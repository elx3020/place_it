# place_it

TypeScript library that places 3D objects on tracked targets (ear, neck) in webcam video. No video leaves the device.

pnpm monorepo: `packages/*` (libraries, scope `@place-it/*`) and `apps/*` (demos).

```
pnpm install
pnpm typecheck && pnpm test && pnpm build && pnpm size
```
